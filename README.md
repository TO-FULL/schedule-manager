# 时砾 · 日程管理网页产品

一个纯前端、无构建、可离线运行的单页日程管理应用。数据保存在浏览器本地（localStorage），不上云。

## 功能模块
- 📊 **总览仪表盘**：进行中任务、今日番茄、专注分钟、最长连续打卡；今日安排、迷你日历、近 7 天专注趋势图、目标倒计时、习惯概览
- 📅 **日历视图**：月历、月份切换、今天高亮、点击日期看当天安排、按分类着色的事件
- ✅ **待办清单**：增删改、优先级（高/中/低）、分类标签、截止日、完成状态、筛选与排序
- 🍅 **番茄时钟**：工作/短休/长休自动循环、可关联当前任务（自动累计番茄数）、结束蜂鸣 + 桌面通知提醒
- 🔥 **习惯打卡**：连续天数（streak）、近 7 天网格、周目标达成率
- 📝 **便签速记**：彩色便签，输入即存
- 🎯 **目标倒计时**：给重要日期做 D-day 提醒
- 🌓 **深色模式**：一键切换
- 💾 **数据管理**：JSON 导出 / 导入 / 清空

## 使用方法
直接用浏览器打开 `index.html` 即可，无需服务器、无需安装依赖。首次打开含示例数据，可在「数据」页清空。

## 技术栈
原生 HTML + CSS + JavaScript（vanilla JS），零依赖、零构建步骤。

## 目录结构
```
schedule-manager/
├─ index.html
└─ assets/
   ├─ css/style.css
   └─ js/
      ├─ app.js         导航路由、主题切换、时钟、角标
      ├─ store.js       localStorage 数据层 + 种子数据 + 导入导出
      ├─ utils.js       toast/弹窗/日期/SVG 图表/蜂鸣/通知
      ├─ calendar.js    月历视图与日程事件
      ├─ tasks.js       待办清单
      ├─ pomodoro.js    番茄时钟
      ├─ habits.js      习惯打卡
      ├─ notes.js       便签
      ├─ dashboard.js   总览仪表盘
      └─ data.js        数据管理
```
